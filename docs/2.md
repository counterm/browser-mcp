这类工具箱的价值排序很明确：先看清 → 再定位 → 再改造 → 最后交给 LLM。下面按你说的四大类拆，每条标了优先级（★★★ 建议首版就做）。

一、提示类：这个页面到底是什么

多数人打开工具箱的第一个问题不是"怎么改"，而是"这页面什么来头"。

功能 说明 优先级

技术栈指纹 识别 React / Vue / Angular / Svelte / jQuery / 纯静态，以及 Next、Nuxt、Vite、umi 等上层框架 ★★★

环境判定 dev / staging / prod，站点版本号（很多站把 __APP_VERSION__ 挂在 window 上） ★★

页面健康度 DOM 节点总数、最深嵌套层数、FCP/LCP、内存占用、监听器数量 ★★

表单字段总览 列出全部 input/select/textarea 的 name、type、是否必填、校验规则 ★★★

接口清单 抓取页面发出的 fetch/XHR，列 URL、method、状态码、耗时 ★★★

第三方 SDK 盘点 埋点、监控、客服插件、A/B 实验脚本 ★

二、查找类：找到那个该死的元素

功能 说明 优先级

元素拾取器 hover 高亮 + 点击锁定，同时输出 CSS / XPath / Playwright / Puppeteer 四种写法 ★★★

Selector 稳定性评分 给生成的 selector 打分并标色 ★★★

按文本/属性搜索 全页搜"提交"，列出所有命中元素并可跳转 ★★★

事件反查 这个按钮绑定了什么 handler ★★★

组件名定位 从 React fiber / Vue 实例拿到组件名 ★★★

全局数据搜索 在 window 对象里搜某关键词，找出 state 藏在哪 ★★

Shadow DOM / iframe 穿透 常规选择器进不去的区域 ★★

层叠与遮挡分析 谁盖住了谁、z-index 全览 ★

表格提取 选中表格 → JSON / CSV ★★

稳定性评分是最能体现专业度的一条。同样是定位一个按钮，#root > div:nth-child(3) > button 改版必炸，而 [data-testid="submit"] 能活很久——给个分数，用户就知道该抄哪个：
function scoreSelector(el) {
  const rules = [
    [/^\[data-testid|^\[data-test|^\[data-cy/, 100, '测试ID，最稳'],
    [/^#[a-zA-Z][\w-]{2,}$/,                    90, '语义化 id'],
    [/^\[aria-label=/,                          85, '无障碍属性'],
    [/^\[name=/,                                80, '表单 name'],
    [/^\.[a-zA-Z][\w-]*$/,                      50, '单类名，可能重复'],
    [/nth-child|nth-of-type/,                   15, '位置依赖，改版必炸'],
    [/^#[\d.]+$|^\._[\w-]+$/,                    5, '自动生成，勿用'],
  ];
  for (const [re, s, why] of rules)
    if (re.test(cssEscape(el))) return { score: s, why };
  return { score: 40, why: '复合选择器' };
}

三、样式与屏蔽类：看清被挡住的东西

功能 说明 优先级

隐藏 / 删除元素 支持撤销，带操作栈 ★★★

移除 position:fixed 浮层 清掉悬浮条、吸顶导航，长截图必备 ★★★

解除滚动锁 干掉 body{overflow:hidden}，解锁锁定页面 ★★★

停用全部动画 注入 * { transition:none !important; animation:none !important }，截图再也不糊 ★★

禁用指定 CSS 规则 直接在 Styles 面板逐条 disable ★★

解除输入限制 去掉 maxlength、readonly、disabled ★★

密码明文切换 type=password → text，自查用 ★★

恢复文本可选 / 右键菜单 解除 user-select:none 与 contextmenu 拦截 ★

元素描边 / 网格叠加 设计走查、对齐检查 ★

变更闪烁 MutationObserver 高亮重绘区域，定位性能抖动 ★★

这一组建议做成可撤销的操作栈——隐藏容易，找回难，用户误点一次就想卸载了。

四、发给 LLM 类：只做两条交付通道（复制 / 存储）

这一组的定位不是"生成命令"，而是把页面产物**交付**给 LLM。页面侧只有两种通道：

- **复制**：结果进剪贴板，人工粘进 LLM 对话，自行沟通（人在环里）。
- **存储**：写入浏览器变量 / localStorage，LLM 经 broker 的 eval / storage 动作自取，无需人工粘贴。

能跑起来的脚本 / 指令不属于这一组，另立「开发产物」类（见下）。

【复制通道】

功能 说明 优先级

一键复制精简 DOM 去噪后压成 Markdown/JSON ★★★

数据脱敏 手机号、身份证、token、邮箱自动打码后再复制 ★★★

选中元素问答 打包元素上下文 + 你的问题，组成一条完整 prompt 复制 ★★★

a11y 修复建议 把元素的可访问性缺陷整理成待办，复制给 LLM ★

【存储通道】

功能 说明 优先级

存入页面上下文 结构化 url/标题/技术栈/表单/表格/接口/精简 DOM 写入 window.__BA_CTX__ 与 localStorage，LLM 经 eval / storage 取 ★★★

存入选中元素 拾取元素 → 写入 window.__BA_EL__，LLM 直接读 ★★

【开发产物（从本组移出，独立成类）】

功能 说明 优先级

生成 Playwright 代码 直接产出可运行定位 / 操作片段 ★★★

生成油猴脚本骨架 @match 填当前域名 + 稳定 selector，省掉全部样板 ★★★

爬虫代码生成 表格/列表 → Python 提取脚本 ★★

操作录制 → 步骤 记录点击序列，导出可重放步骤 ★★

精简 DOM 的核心不是裁剪长度，而是保留可交互元素、丢掉装饰性噪声，否则 3000 token 里 2800 个是 div 和 svg：
function skeleton(root = document.body) {
  const clone = root.cloneNode(true);
  clone.querySelectorAll('script,style,svg,path,noscript').forEach(n => n.remove());
  // 只保留有信息量的属性
  clone.querySelectorAll('*').forEach(n => {
    [...n.attributes].forEach(a => {
      if (!/^(id|class|href|src|name|type|value|placeholder|aria-label|data-(testid|test|cy|id))/i.test(a.name))
        n.removeAttribute(a.name);
    });
  });
  return clone.innerHTML;
}


我的 MVP 建议

首版做这 6 个就够了，能覆盖 80% 的使用场景：

1. 元素拾取器 + 四种 selector 输出 + 稳定性评分
2. 技术栈指纹 + 环境判定
3. 隐藏元素 / 移除 fixed 浮层 / 解除滚动锁（带撤销栈）
4. 表单字段总览 + 接口清单
5. 一键复制精简 DOM（含脱敏）
6. 生成 Playwright 定位代码 + 油猴脚本骨架

漂浮按钮本身建议做成可拖拽 + 记忆位置 + 滚轮穿透，别挡正文；再配一个全局快捷键（如 Alt+Shift+D）唤起，比点按钮快得多。

最后问一句：这个扩展主要是你自己和同事调试用，还是要给测试/运营这类非开发者用？如果是后者，"事件反查""fiber 组件名"这种硬核项要折叠进高级区，主界面换成"点一下就能复制选择器"这种零门槛操作——两套信息架构差别挺大的。
