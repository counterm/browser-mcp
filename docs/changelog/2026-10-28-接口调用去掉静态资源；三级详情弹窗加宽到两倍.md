# 2026-10-28 · 接口调用去掉静态资源；三级详情弹窗加宽到两倍

- **问题**：「接口调用」列表里混进图片地址——bg 侧 webRequest 把所有 http(s) 请求都记成「仅头」记录，`image` / `css` / `js` / `font` 等静态资源也在内
