# 2026-11-04 · feat: flow 点击步记录页面绝对坐标，同构节点按最近坐标选取

- 背景：仅靠「选择器 + 第一个可见节点」仍会点错——列表里每行都有同构的「详情」按钮，选中第一个可见的会开到别的行；框架还会把同名 `aria-label` 挂在隐藏节点上
- 录制（`toolbox/feats/build.js`，两棵树同步）：`recOnClick` 新增 `recPos()`，记录目标中心点的**页面绝对坐标** = `getBoundingClientRect` + `scrollX` / `scrollY`（录制时已滚动也能换算成文档坐标），写入步骤 `x` / `y`；`stepsYaml` 对 `x` / `y` 输出数字而非字符串
- 回放（`content.js`）：`selectorPick(sel, p)` 先取可见候选，多个可见候选且带 `x` / `y` 时按中心点绝对坐标的平方距离取最近的一个；仍无可用的可见候选则退回首个命中（保持旧行为）。纯数字 selector（bid）不受影响
- 滚动处理：两侧都用 `getBoundingClientRect + scrollX/scrollY` 换算到页面绝对坐标，回放时整页滚动位置不同也不影响比对（元素在普通文档流中绝对坐标不随滚动变化）
- `flowrun.js` 的步骤摘要（`brief`）加入 `x` / `y`，轨迹里能看到坐标；`docs/spec-flow.md` 补充字段说明
- `node --check` 通过（content.js / flowrun.js / 两棵树的 build.js）
