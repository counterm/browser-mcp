# 2026-11-04 · feat: 工具箱设置面板与操作记录，录制 flow 改为点击即录

- 录制入口：`record` 更名为「录制 flow」（英文 Record Flow），新增 `direct:true`——在二级列表点击后不再打开三级详情，直接开始录制；停止时按设置自动复制 YAML 并恢复面板
- 设置面板：面板页脚新增「设置」入口，二级弹窗展示配置（非功能选项）：界面语言（中文 / English）、「直接复制到剪贴板」开关（默认开启）
- 操作记录：`core.js` 新增 `B.rec`，所有工具结果统一写入 `localStorage["ba:tbx-records"]`（约 100KB，超出按时间丢弃最早，最多 200 条）；设置面板按时间倒序列出记录，支持逐条手动复制与清空
- 记录来源：① 统一收口 `B.u.copyText`（自动复制与手动复制都会落记录）；② 三级详情执行完成后，若渲染出 `pre` / `.kv` / `.lst` / `img` 结果，自动记录；15 秒内同一功能的记录合并为一条，避免「预览 + 复制」重复
- 「直接复制到剪贴板」只控制自动交付（如录制停止）是否真正写入剪贴板；关闭后结果仍完整记录，可在设置面板手动复制
- 两棵树同步：`core.js`（配置 / 记录 / 样式）、`ui.js`（设置面板、直接执行型功能、结果记录）、`boot.js`（设置入口绑定）、`feats/build.js`（录制简化）均同步 `chrome-extension/toolbox` 与 `docs/toolbox`
- `node --check` 通过（两棵树的 core / ui / boot / feats/build）
- 后续修正：记录区标题不再展示总上限（`1 条 · 本地约 100KB` 易被误读成单条体积），改为只显示实际占用，如 `操作记录（3 条 · 占用 1.6 KB）`；`B.rec.used()` 返回 localStorage 实际字节数
