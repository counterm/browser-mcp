# 2026-11-04 · fix: 快捷键改为复选框 + 单字符输入，避免被其它扩展捷取

- 设置面板的「唤起快捷键」不再依赖真实按键捕获：改为 `Ctrl / Alt / Shift / Meta` 四个复选框 + 1 个字母或数字输入框 + 「保存」
- 原因：捕获模式下用户按下的组合可能先被浏览器或其它扩展吞掉，工具根本收不到 `keydown`，导致「按了没反应」
- 交互细节：输入框自动转大写并过滤非 `A-Z0-9` 字符；保存时至少勾选一个修饰键，否则提示；保存后立即写入配置并重绘，生效后旧组合不再响应
- 组合键格式保持 `Ctrl+Shift+K` 形式，`B.hotkeyParts` / `B.hotkeyMatch` 无需改动，扩展级全局配置同步照旧
- 移除 `beginHotkeyCapture / stopHotkeyCapture / onHotkeyCapture` 与 `hotkeyCapture` 状态
- 两棵树同步：`chrome-extension/toolbox/ui.js`、`ui.js` 与 `core.js`（新增 `.hk-edit / .hk-cb / .hk-key` 样式）
- `node --check` 通过；原型实测：`Alt+Shift+D` → 改为 `Ctrl+Shift+K` 后新组合可唤起、旧组合不再触发
