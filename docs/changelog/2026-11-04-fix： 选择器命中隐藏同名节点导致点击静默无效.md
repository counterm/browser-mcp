# 2026-11-04 · fix: 选择器命中隐藏同名节点导致点击静默无效

- 问题：Element Plus 页面里 `el-drawer__close-btn`（隐藏）与 `el-dialog__headerbtn`（可见）共用 `aria-label="关闭此对话框"`，且 drawer 节点在 DOM 中排在前面。flow 的 `selector: "[aria-label=\"关闭此对话框\"]"` 被 `document.querySelector` 解析成隐藏的 drawer 按钮，`click` 照常返回成功、步骤显示 OK，但弹窗并未关闭——表现为「最后一步执行不了」却又没有报错
- 修复：`content.js` 新增 `selectorPick()`，CSS 选择器命中多个节点时优先返回可见的那个，全部不可见时才退回首个命中（保持旧行为）；`locate()` 的 `selector` 分支改用它，`click` / `type` / `press` / `select` 等定位类动作一并受益。纯数字仍按 bid 解析
- 存量 flow 无需改动，扩展重载 + 刷新目标页面后生效
- `node --check` 通过（content.js / flowrun.js）
